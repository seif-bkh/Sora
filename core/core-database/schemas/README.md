# Exported Room schemas

Generated by the Room Gradle plugin into `<variant>/<database>/<version>.json`
and **committed on purpose** - `MigrationTestHelper` reads them to build an
old-version database and to validate the result of a migration, so migration
tests cannot run without them.

The build also maps this folder in as a unit-test asset source (see
`core-database/build.gradle.kts`), which is where the helper looks at runtime.

Do not hand-edit these files. Bump `SoraDatabase.VERSION`, add a `Migration`
in `SoraMigrations`, and let the build regenerate the JSON.
